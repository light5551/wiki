## Процесс обучения
Пайплайн обучения состоит циклических этапов:
1. Обучение модели мира с замороженным Actor'ом
2. Замороженная модель мира и обучение actor
3. Переход к 1 этапу пока не закончится обучение

### Чуть подробнее про первый этап(см. 1 картинку)
По "World Model Learning":
1. Observation вместе со h_t(скрытое состояние) подается на вход Encoder'у и генерируется латентный вектор z_t, который описывает *настоящее* с учетом прошлого(для этого и подается скрытый вектор h_t). На 1 итерации создается рандомный(или нулевой) скрытый вектор h_0. 
2. В decoder подается вектор z_t для явного восстановления observation. 
3. Полученный вектор z_t и h_t вместе с a_t(действие агента в момент времени t) подаются на вход sequential_model(на 3 картинке функция f), которая выдает следующий h_t+1.  В качестве действий используются действия замороженного на этом этапе actor'a.  

Параллельно обучаются другие модели:
1. Модель динамики, которая учится предсказывать z_t по h_t
2. Модель, которая предсказывает оценку(reward) по h_t, z_t
3. Continue predictor (или для простоты, predictor терминальных состояний) предсказывает является ли нынешнее состояние терминальным, т.е. достиг ли агента своей цели, ижи наоборот совершил ошибку
